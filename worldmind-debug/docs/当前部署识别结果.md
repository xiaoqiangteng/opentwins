## 常见错误

- `kubectl get pods` 长时间无响应：说明 minikube 或 kubeconfig 状态异常，可先用 NodePort HTTP 检查确认核心服务是否可达。
- `Ditto API 不可达`：检查 `OPENTWINS_HOST_IP` 是否等于当前 `minikube ip`。
- `InfluxDB 查询为空`：先确认 Telegraf 是否运行，再确认 bucket、measurement 和时间范围。

## 排障步骤

1. `./watch_demo.sh --status` 看 Demo 进程与基础设施连通性。
2. `worldmind-debug/cli/wmctl doctor` 看 MQTT、Ditto、InfluxDB、Grafana 的统一结果。
3. `worldmind-debug/cli/wmctl mqtt tail --topic 'telemetry/#' --seconds 10` 检查入口数据。
4. `worldmind-debug/cli/wmctl twin echo wine:tank_001` 检查 Ditto 当前状态。
5. `worldmind-debug/cli/wmctl influx recent --measurement tank_001 --minutes 60` 检查时序库。
